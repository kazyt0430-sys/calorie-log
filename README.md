# Calorie Log

iPhone Safariで日常利用するための、追加ランニングコスト0円のカロリー・PFC管理Webアプリです。

公開版: https://kazyt0430-sys.github.io/calorie-log/

現在のリリースは `v1.2.0` です。

## 使い方

GitHub Pagesなどの静的ホスティングにこのリポジトリ直下を公開します。端末内の `localStorage` に保存するため、外部DBや有料APIは不要です。

ローカル確認:

```powershell
& 'C:\Users\kt_43\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' tests/core.test.js
```

## 主な機能

- 今日の摂取kcal、残りkcal、P/F/C残量
- 朝食・昼食・夕食・間食の食事記録
- 食品検索、食品追加、数量変更、削除
- お気に入り、最近使った食品、自分専用食品登録
- 日付切替、食事履歴、体重記録
- 7日分析、30日分析
- 目標カロリー・PFC設定、プロフィールから目安計算
- 残りkcal/PFCに基づく食事候補
- JSONバックアップ・復元
- 写真撮影/選択、端末内解析による食品候補ランキング
- 食品候補の変更、食品別の量・個数選択、PFC確認後の記録
- 食事テンプレートの一括追加と保存
- 写真メモ
- パッケージの栄養成分表示を端末内OCRし、編集確認して食事登録
- 1個・半分・2個などの数量変更に応じたkcal/P/F/C再計算
- PWA、ホーム画面追加、オフライン利用

## 写真機能

有料AI APIは使わず、写真の色・明るさを端末内のCanvasだけで解析します。推定結果は確率順の候補として表示され、第1候補が初期選択されます。画像だけでは料理名や量を正確に断定できないため、候補と量を確認・変更してから記録する設計です。画像認識の差し替え口は `photo-recognition.js` に分離しています。

「栄養表示を読み取る」では、Tesseract.js v6（WebAssembly）と日本語・英語モデルを必要時に無料CDNから読み込み、画像と文字認識をブラウザ内だけで処理します。初回はモデル取得のため通信と待ち時間が発生します。OCR結果は自動確定せず、商品名、基準、kcal、P/F/C、食塩、糖質、食物繊維を修正してから登録できます。OCRに失敗しても手動入力画面が表示されます。

HEICはiOS Safariが画像として展開できる場合に対応します。写真は最大辺1600pxへ縮小してメモリ使用量を抑えますが、暗い・傾いた・反射したラベルや複雑な表組みでは誤認識があるため、登録前の確認が必要です。
